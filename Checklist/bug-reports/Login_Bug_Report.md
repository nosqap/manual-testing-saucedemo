# Bug Report — Login Error Message

## Title
Login error message is too long and technical

## Steps to Reproduce
1. Open the Login page.
2. Enter correct username.
3. Enter wrong password.
4. Click Login.

## Actual Result
The system displays: "Username and password do not match any user in this service".

## Expected Result
The system should display a shorter and clearer message for the user.

## Severity
Low

## Priority
Low

## Status

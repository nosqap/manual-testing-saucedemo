# Manual Testing Portfolio – SauceDemo

## Project Overview

Manual testing of the SauceDemo e-commerce web application.

## Scope

- Login
- Products
- Cart
- Checkout
- Logout

## Testing Types

- Functional Testing
- UI Testing
- Positive Testing
- Negative Testing

## Repository Structure

- /checklists — checklists for Login, Products, Cart, Checkout, Logout
- /test-cases — test cases for Login and Products
- /bug-reports — bug reports
- /docs — README and Test Summary Report

## Deliverables

- Test Plan
- Checklists
- Test Cases
- Bug Reports
- Test Summary Report
